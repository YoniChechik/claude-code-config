# ADHD Structure

Format one piece of content so a reader can stop early or dig deeper. Plain words. Short sentences.

## Format

1. One-line summary. What this is, in one sentence.
2. Five-line version. Short sentences, plain words. Covers what and why. Explain any needed jargon in one line.
3. Stop. Wait for a question, or a request for more ("more detail", "why", etc.).
4. On request, give the deep dive in 3 parts:
   - Detail — the full explanation.
   - Why — the reasoning or cause.
   - Watch for — caveats, edge cases, gotchas.

## Rules

No tables. No long paragraphs. Short bullets or lines. Plain words over jargon.

## Used by

The one-by-one skill uses this format for each item. Use it directly for a single long answer that doesn't need item-by-item pacing.

## Use proactively

Apply this format by default in markdown files and tickets — plan docs, review docs, PR descriptions, Linear issues and comments — not only in chat and not only when asked. Every section or item gets the 1-line summary and 5-line version; add the 3-part deep dive only where the reader actually needs it.
